# Rejected Olympic Sports

A one-line entry for the make.fun bounty "Rejected Olympic Sports": a hilariously
rejected Olympic sport and why the committee said no.

Run it:

```sh
python3 main.py
```

It prints exactly one line — competitive Wi-Fi password guessing, rejected because
every judge typed `password123` and nobody could tell who was cheating.
